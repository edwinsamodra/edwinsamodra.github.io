# Edwin Samodra - Personal Website

This is the source code for my personal portfolio website.

## Tech Stack

- **Framework:** Nuxt 4
- **UI Library:** Nuxt UI
- **Styling:** Tailwind CSS (Nuxt UI)
- **Icons:** Lucide & Simple Icons (Iconify)
- **Language:** TypeScript
- **Package Manager:** pnpm
- **Deployment:** Cloudflare Workers
